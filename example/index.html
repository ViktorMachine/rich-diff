API 参考

diffText(oldText, newText, fieldName)

对比纯文本，返回 { html, useShadowDOM, markers }

diffHTML(oldHtml, newHtml, fieldName)

对比 HTML/富文本，支持 ShadowDOM 降级兼容

diffMediaList(oldList, newList, idField)

对比媒体资源列表，返回 { newList, oldList }

generateMarkers(diffResult, options)

从差异结果中提取变更标记数组

setEngine(engine)

切换对比引擎: 'htmldiff' 或 'diffdom'

代码示例

import {
  diffHTML,
  diffText,
  generateMarkers,
  setEngine,
  diffMediaList
} from 'rich-diff'

// 1. 切换引擎（可选）
setEngine('diffdom')

// 2. 纯文本对比
const textResult = diffText('旧标题', '新标题', 'title')
console.log(textResult.html) // '旧新标题'

// 3. HTML 对比
const htmlResult = diffHTML(oldHtml, newHtml, 'content')

// 4. 媒体对比
const { newList, oldList } = diffMediaList(oldMedia, newMedia)
// newList 中每项带有 diffType: 'add' | 'del' | 'alter' | 'same'
